# VpnService 抓会话实测记录（2026-11-24）

环境：PMA110（Android），入库助手 v1.1.6  
目标：只把 `com.slh_mobile_pro` 放进 VPN，HTTP 指向本机 `127.0.0.1:8899`；不依赖 Shizuku，也不改系统全局代理。

## 过程

1. 点「抓取登录会话」，允许系统 VPN 授权
2. App 建立只允许商陆花的 VPN，并启动本地代理
3. 强制重启商陆花，等它启动并同步
4. 代理拦截 `dsa13a…:8413` 数据隧道，逼商陆花回发明文接口

结果：约 **8 秒**抓到会话；VPN 关闭，`tun0` 消失，系统代理保持 `:0`。

## 注意

- 首次需要系统 VPN 授权；之后直接启动
- 抓会话前要关掉梯子 / 其他 VPN，同一时间只能一个 VPN
- 拦截数据隧道时商陆花可能短暂报错，抓到后 VPN 关闭即可恢复
- sessionid 是登录凭证，日志和 issue 里不要贴完整值
