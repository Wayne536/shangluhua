# 网页版（稳定版，已验证）

**状态：可用。** 这是目前唯一经过实际入库验证的版本，2026-11-23 备份。

## 它做什么

手机浏览器打开一个网页，把微信笔记粘进去，点「开始入库」，就自动：

1. 解析笔记（款号 / 名称 / 颜色 / 尺码）
2. 查重（已存在的跳过）
3. 缺的颜色自动在商陆花里创建
4. 调商陆花接口建货品（库存 0）
5. 可选上传最多 9 张图
6. 批量队列 + 实时进度

## 怎么跑

```bash
cd /root/workspace
python3 entry.py          # 监听 127.0.0.1:5055
```

浏览器打开 `http://127.0.0.1:5055`

首次入库需要会话（sessionid），由 `session.py` 通过 adb + 本地 mitmproxy 抓取，
抓完会自动撤销手机代理。

## 文件说明

| 文件 | 作用 |
|---|---|
| `entry.py` | 网页服务（页面 + 接口 + 队列） |
| `api_import.py` | 商陆花接口封装（建货品、字典、传图） |
| `note_parser.py` | 笔记解析 |
| `session.py` | 抓 sessionid（mitmproxy + 手机代理） |
| `ocr.py` | 图片识别颜色（已停用，太慢） |
| `cap.py` / `cap2.py` | mitmproxy 抓包插件 |
| `slh_import.py` | 早期 UI 自动化版（已归档） |
| `slh_adb.py` | adb 基础封装 |

## 已知限制

- 需要 adb 连接手机（抓会话用）
- 需要商陆花 App 处于登录状态
- 服务只监听 127.0.0.1，其他设备访问需要改成 0.0.0.0
- 会话每次 App 重启会变，需要重新抓
